# MATLAB benchmark

The frozen MATLAB implementation used for the UFLN paper will be curated here.

The final structure will separate, as far as practical:

- benchmark entry points and experiment schedules;
- waypoint-generation methods;
- landmark visibility and selection;
- execution and safety;
- motion control;
- corpus/map handling;
- validation and integrity checks; and
- figure/result generation.

The publication release will document the exact entry points required to reproduce the frozen V2.2.1 experiments.
